# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to:

soulbialogur@gmail.com

Please do not open public issues for security-sensitive problems until a fix has been prepared and disclosed responsibly.

## Supported versions

The project currently supports the latest main branch and the latest release tag. Older revisions are not guaranteed to receive security fixes.

## Disclosure timeline

We aim to acknowledge reports within 5 business days and work toward a fix as quickly as possible. Public disclosure will be coordinated with the reporter when appropriate.
